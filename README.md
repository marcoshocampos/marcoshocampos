## 👋 Sobre mim

Desenvolvedor backend com **4+ anos** construindo e sustentando **ERPs e CRMs de grande escala em PHP**. Meu trabalho começa onde o sistema cresceu: a consulta que trava, a fila que acumula, o legado que ninguém quer abrir.

- 🏢 Hoje sou **Desenvolvedor Backend Pleno** na **South**
- 🐘 Mais rápido em **PHP/Laravel**, mas o que levo para qualquer stack não muda de linguagem: modelagem de dados, desenho de API, filas, cache, testes e leitura de código legado
- 🐹 Já entreguei features em **Go** em integrações entre serviços — e encaro **Vue.js** no front quando o time precisa
- 🤖 Uso **IA no ciclo de desenvolvimento** (geração e revisão de código, automação, prototipação) — sem abrir mão de revisão humana
- 🎓 Bacharel em **Sistemas de Informação** pela **PUC Minas**
- 💬 Aberto a conversas sobre posições de **back-end** — PHP/Laravel ou outra stack

```php
<?php

final class MarcosHenrique extends BackendDeveloper
{
    public string $role     = 'Desenvolvedor Backend Pleno';
    public string $location = 'Belo Horizonte, MG 🇧🇷';

    public array $dailyStack = ['PHP', 'Laravel', 'Yii2', 'Go', 'MySQL', 'Redis', 'RabbitMQ'];

    public function solve(Problem $problem): Solution
    {
        return match (true) {
            $problem->isSlowQuery()   => $this->explain()->index()->rewrite(),
            $problem->isQueueBacklog() => $this->scaleConsumers()->makeAsync(),
            $problem->isLegacyCode()   => $this->writeTests()->refactor(), // SOLID, sem medo
            default                    => $this->readTheCodeFirst(),
        };
    }
}
```
